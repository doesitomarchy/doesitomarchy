OmaBoot? fixes

#WeCanFixEverything

OmaBoot? tests Macs from a live boot, and carries a few fixes that stock Omarchy doesn't have yet, so a Mac that needs one can still be tested. A report lists the fixes that took effect. Its results count for the configuration as usual, marked with OmaBoot? <fix>, linked to the fix's entry below.

Where fixes really happen

A fix here is a stopgap. The lasting fix lands upstream, where every Mac gets it:

  • Kernel drivers: the Linux kernel mailing lists and the subsystem's maintainers (listed in the kernel's MAINTAINERS file).
  • T2 and Apple hardware patches: t2linux, and its kernel patches.
  • Omarchy itself: omacom/omarchy, and omacom/omarchy-pkgs for its linux-omarchy kernel.
  • Packaging: Arch Linux packaging.

Found what a Mac needs? Send it upstream, then tell us: once it ships in Omarchy, a new report turns the result green.
