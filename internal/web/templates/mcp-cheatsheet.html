Reading the answers

  • Verdicts belong to configurations, not Macs. Untested means no report yet, not that it fails.
  • Configuration IDs look like {{.ExampleConfig}}; a wrong one lists the valid ones.
  • A Mac sold under several names is named after the release asked about; get_mac for the whole Mac adds "Also sold as".
  • "Note: field: expected …" means the value is invalid, not merely unmatched.
  • Answers link to the pages on doesitomarchy.com and name Macs as "Name [Identifier]".
