Data

  • Test criteria: generalised from Boyd's Vintage Mac Compatibility Test Criteria.
  • Hardware probes: linuxhw LsPCI, LsUSB and Dmesg datasets, from real Linux machines.
  • Board IDs and model metadata: the OpenCore AppleModels database (BSD-3-Clause).
  • Specifications: Apple Support identification and Tech Specs pages, and EveryMac; each model page links its sources.
  • PCI device names: the PCI ID Repository.
