Register a report source

A source is a test tool that sends diagnostic reports to DoesItOmarchy. Ask for a source key here. A maintainer reviews every request by hand, and you collect the key from a private link.

What makes a useful source

  • It runs on Omarchy, on a real Intel Mac, and checks the criteria it can: by itself where it can, by asking the tester where it can't.
  • It reads the Mac's hardware IDs (model identifier, board ID, CPU and PCI IDs), so each report finds its configuration.
  • It says what it saw: the evidence for anything that fails or only partly works.
  • It shows testers the consent notice and lets them stop before anything is sent.
  • Its source code is public, so testers and maintainers can see what it checks.

The technical details are on the API page: becoming a source, submitting a report and the report format.
