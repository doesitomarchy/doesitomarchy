Contribute

Fix or improve the catalog

The catalog is plain YAML in the doesitomarchy repository: one file per model identifier in data/macs/, shared components in data/components/. Corrections come in as pull requests. doiomad validate checks every change in CI.

  • Cite a source for every fact: Apple Tech Specs, EveryMac, or a hardware probe from a real machine.
  • If you're unsure, record your best value with an uncertain note rather than guessing.
  • Configuration IDs are permanent. Rename one by moving the old ID to aliases, never by deleting it.

See CONTRIBUTING.md for the full rules.

Report a test result

Test results open with the site's submission API, which is still being built. Once it's ready you'll be able to report how Omarchy runs on your Mac, capability by capability, and every result will be reviewed before it counts.

Until then, the most useful thing you can do is check that your Mac's model page matches your hardware. If it doesn't, open an issue with the output of lspci -nn and lsusb.
