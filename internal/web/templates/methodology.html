Methodology

DoesItOmarchy tracks whether Omarchy works on every Intel Mac Apple sold from 2006 to 2020. Each Mac is identified by its model identifier (for example MacBookPro8,2, shown in System Information). Every official hardware configuration of each identifier is listed as a complete computer.

Only tests count

Every capability starts as Untested. A status only changes when someone runs Omarchy on that configuration and reports the result. Research notes on model pages come from spec sheets and Linux hardware probes. They are labelled unverified and never change a status.

Configurations

A release is split into configurations when the parts Omarchy Linux cares about differ: the GPU, Wi-Fi, Bluetooth, Ethernet, audio codec, storage controller or security chip, or the ports and features that decide which tests apply. CPU speed, RAM and disk size are attributes of a configuration, not separate ones. Rebadges of the same chip share a configuration. Each configuration is named by what sets it apart from its siblings, such as its GPU, screen size or release.

Each test run is a diagnostic report. For each capability, the report from the newest Omarchy version wins. Reports from an older Omarchy major version are marked stale. Two reports for the same Omarchy version that disagree are shown as conflicting. All times are UTC.

Sources

Hardware facts come from Apple's identification and Tech Specs pages, EveryMac, the OpenCore model database, and real-machine Linux hardware probes from linuxhw. Chips and hardware IDs seen on real machines count as evidence. Where sources disagree, the model page's research notes say so. Every model page lists its sources. See attribution for credits.
