Methodology

DoesItOmarchy tracks whether Omarchy works on every Intel Mac Apple sold from 2006 to 2020. Each Mac is identified by its model identifier (for example MacBookPro8,2, shown in System Information). Every official hardware configuration of each identifier is listed as a complete computer.

Only tests count

Every capability starts as Untested. A status only changes when someone runs Omarchy on that configuration and reports the result. Research notes on model pages come from spec sheets and Linux hardware probes. They are labelled unverified and never change a status.

Configurations

A release is split into configurations when the parts Linux cares about differ: the GPU, Wi-Fi, Bluetooth, Ethernet, audio codec, storage controller or security chip, or the ports and features that decide which tests apply. CPU speed, RAM and disk size are attributes of a configuration, not separate ones. Rebadges of the same chip share a configuration. Each configuration is named by what sets it apart from its siblings, such as its GPU, screen size or release.

Verdicts

Each configuration gets one verdict, applied in this order:

  1. {{template "verdict" (v "not-compatible")}} the Mac can never run Omarchy by design. Today that means the 2006 Macs with a 32-bit-only Core Duo CPU, since Omarchy and Arch Linux support x86_64 only.
  2. {{template "verdict" (v "untested")}} no test result yet.
  3. {{template "verdict" (v "unsupported")}} a Boot capability fails.
  4. {{template "verdict" (v "partial")}} something else fails or only partly works, or reports conflict.
  5. {{template "verdict" (v "supported")}} every tested capability works, shown with how many were tested.

A configuration whose every applicable capability has passed earns the Omarchy mark {{template "badge"}}. So does a model identifier whose every configuration has passed. The newest Omarchy version's result wins. Results from an older Omarchy major version are marked stale. Two results for the same Omarchy version that disagree are shown as conflicting.

Coverage

Compatibility coverage counts configurations where every applicable capability has passed. Test result coverage counts those with at least one result. Both leave out configurations that are not compatible by design, and those outside the coverage scope: Macs released before 2009 and the Xserve. Out-of-scope Macs are still listed and can still be tested.

Each configuration shows only the criteria that apply to its hardware. They are generalised from Boyd's Vintage Mac Compatibility Test Criteria. The criteria matrix shows which configurations each one applies to.

Sources

Hardware facts come from Apple's identification and Tech Specs pages, EveryMac, the OpenCore model database, and real-machine Linux hardware probes from linuxhw. Chips and hardware IDs seen on real machines count as evidence. Where sources disagree, the model page's research notes say so. Every model page lists its sources. See attribution for credits.
